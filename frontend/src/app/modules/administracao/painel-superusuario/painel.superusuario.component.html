Como alimentar as métricas pelo n8n

Depois do envio confirmado, use um nó HTTP Request para registrar o evento em POST /api/integracoes/mensagens, com a credencial de integração no cabeçalho X-Token-Metricas.

Informe a empresa, um ID estável do evento, a origem, a direção, o resultado e a data. Repetir o mesmo evento não aumenta os números.

A credencial fica no backend e no n8n. Ela permite registrar eventos, sem acessar o painel ou editar o prompt global.
